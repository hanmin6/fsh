# 微信接入与多账号管理

- 左侧新增“微信接入”，沿用工作台导航、路由和品牌样式。
- 账号列表加详情面板；新增、重命名、启停提醒、断开 CRM 连接、测试通知。
- 每个账号独立二维码及登录版本；手动刷新、倒计时、等待扫码、手机确认、输入微信配对码、过期与网络失败状态。
- 对接腾讯 iLink 接口，不用模拟 QR。刷新后的旧轮询不可写入新版本；同一微信不能重复绑定到不同账号记录。
- 所有接入管理 API 需要 CRM 管理员身份。匿名、普通用户不能查看 QR 或凭据；浏览器不接收 bot token、用户完整 ID 或轮询游标。
- 私有存储位于 CRM data/fusanhe，原子写入及文件锁；外部请求在锁外执行。二维码和通知禁缓存，测试有发送间隔与结果状态。
- 既有 Mac OpenClaw 连接保留；CRM 接入账号需在新页面完成扫码，不搬运现有凭据。此阶段不启用定时晨报、客户自动发送或新的模型服务。

验收：多账号独立 QR、刷新和旧响应隔离、重复微信拒绝、权限门禁、凭据不出 API、过期/失败恢复、真实服务器 QR 获取及桌面/窄屏页面操作。
