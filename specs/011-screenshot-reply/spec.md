# Feature Specification: 截图帮我回复

**Feature Branch**: `codex/screenshot-reply`
**Created**: 2026-10-15
**Status**: Approved for implementation by user
**Input**: 上传聊天截图后，AI 先给几个方向，加自定义框，再生成回复。

## User Scenarios & Testing
### User Story 1 - 看截图，选择回复思路 (Priority: P1)
业务员上传、粘贴或拖入 1–3 张客户聊天截图，查看可修正的识别文字及中文诉求摘要，再从三个不同方向中选择。
**Independent Test**: 使用合成询价截图，识别文字可修改、三个方向可选择，模糊或无聊天内容图片显示补充提示。
**Acceptance Scenarios**:
1. Given 有效截图，When 分析，Then 展示识别文字、摘要、建议语言、三个方向或明确的无法识别提示。
2. Given 修改识别文字或更换截图，When 重新分析，Then 旧方向及结果失效，失败不丢失输入。
### User Story 2 - 自定义并生成可用回复 (Priority: P1)
可选择方向加补充要求，也可直接自定义；正文可编辑，提供中文释义，支持复制和简短/自然/正式改写。
**Independent Test**: 不选方向仅输入自定义要求，也能生成；更换方向保留输入。
**Acceptance Scenarios**:
1. Given 已有识别文字，When 选择方向或输入自定义想法并生成，Then 显示可编辑正文、中文释义及独立待确认事项。
2. Given 自定义与方向冲突，When 生成，Then 明确提示按自定义执行，不擅自承诺商业条件。
3. Given 已编辑正文，When 复制，Then 只复制正文；旧释义显示需重新生成，避免误以为仍对应编辑后的正文。
### User Story 3 - 从现有会话使用 (Priority: P2)
消息中心可进入帮我回复并带入最近会话文字。可保存为原会话人工草稿，沿用审核流程。
**Independent Test**: 会话入口带入文字，保存明确显示未发送；独立截图不伪造会话关系。

### Edge Cases
无文件、空文字、非图片、损坏图片、超过数量/大小/像素限制、重复点击、卸载中请求返回、模型未配置、超时、无效结构响应、剪贴板失败、无权限、小屏、键盘操作均有明确处理。

## Requirements
### Functional Requirements
- **FR-001**: 主导航「消息中心」后新增「AI 帮我回复」，保持原界面视觉风格。
- **FR-002**: 支持 PNG/JPEG/WebP，最多 3 张，每张 4 MiB，总计 8 MiB，按顺序预览和删除；支持文本备用输入。
- **FR-003**: AI 先输出可编辑识别内容、中文摘要、语言和三个具体回复方向；无可读内容不得虚构。
- **FR-004**: 方向可取消；自定义框始终可用。选择方向或填写自定义内容才可生成；冲突时自定义优先并提示。
- **FR-005**: 回复正文可编辑、复制、改写，中文释义和待确认事项与正文分离；保留输入以支持失败重试。
- **FR-006**: 不自动发送。会话草稿沿用原审核流程，保存不重复创建（当前页面成功后禁用重复保存，失败不自动重试）。
- **FR-007**: 服务端检查登录和草稿创建权限；会话加载遵守原读取权限。截图仅请求期间处理，不写数据库、日志、浏览器持久化或仓库。
- **FR-008**: 未配置 AI 或无效响应须明确报错；示例模式仅使用标注的合成示例，不声称识别了上传图片。
- **FR-009**: 截图及客户文字是非可信材料，不能改变系统指令。无已确认资料时不生成价格/交期/认证等事实承诺。
- **FR-010**: 增加行为、契约和安全验证，记录实际验证范围及未完成外部验收。
### Key Entities
- Reply session: 临时截图、识别文本、方向、补充要求、语言、正文、释义、待确认事项。
- Existing conversation/draft: 只通过原有接口关联、保存，不新增数据库实体。

## Success Criteria
- **SC-001**: 合成场景完成上传到复制的完整流程，包含方向选择及纯自定义两条路径。
- **SC-002**: 改变材料后无法误用旧结果；失败时输入仍在。
- **SC-003**: 390px 和 1440px 页面可操作，无横向溢出；键盘可完成主要流程。
- **SC-004**: 无配置、无权限、无效图片和无效模型响应均不产生假成功或外发。

## Assumptions
- 首版接入已有兼容 OpenAI 的服务，固定使用 GPT-6.1 Sol（`gpt-6.1-sol`），必须匹配服务端返回模型；未配置时不降级为假识别。
- 用户已明确授权将主动提交的截图交由 AI 分析；此授权仅覆盖本功能提交内容，不覆盖后台批量提取客户资料。
- 本次开发不等同部署。生产密钥、实际截图效果及真实渠道发送不作为本地模拟验证结论。

## 发布补充（2026-10-15）
用户要求截图识别及回复生成均使用 GPT-6.1 Sol（`gpt-6.1-sol`）。不接受网关模型替换；无配置、未完成响应、模型不匹配均失败关闭。功能移植到最新 main，保留获客、微信、AI Sales 和现有工作台行为。
