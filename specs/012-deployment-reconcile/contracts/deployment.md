# Deployment contract

- Expected fingerprints must match before production writes.
- Backup includes nonempty consistent database dump, restricted data/source/env archives, SHA-256 manifest and verified isolated restoration.
- Keep native login, paused outbound, persistent volumes, independent gateway state and existing domain configuration.
- Existing evidence APIs follow specs/009-outreach-evidence-research; no expanded permissions or sends.
- Only confirmed web entry ports may be exposed. Keep CRM origin, database, file sharing and administration private.
- Direct access success requires verified WAN/router/provider conditions, external strict TLS, login rejection for anonymous requests and WebSocket validation.
- Missing prerequisites remain documented pending work; do not point DNS at an unverified address.
