# crm-web 文字设计方案 v1

日期：2026-09-30。

本方案描述统一后的产品体验，以现有 crm-web 的五页工作台为基础，纳入 HIG 的主要业务功能。不讨论代码、接口和实现难度。

## 1. 工作台定位

面向福三和日常业务人员和业务主管，集中完成查看询盘、回复审核、客户跟进、资料核对和内容创作。打开首页后，能立即判断两个平台是否正常抓取，找到要处理的新消息和下一步客户行动。

保留五个一级页面：

1. 首页
2. 消息中心
3. 客户与评级
4. AI 工作中心
5. 知识库

设置放在导航底部。业务详情使用页面内的侧栏、子标签或详情页，主要流程在同一工作台内完成。

## 2. 整体布局与视觉

左侧为可收起的导航；顶部为当前页面、全局搜索和个人信息；中间为主要内容；右侧仅在查看客户、会话或资料时出现详情栏。

视觉沿用 crm-web 的品牌与简洁布局：白色或浅灰背景、清楚的文字层次、细分隔线、紧凑的列表与表格。品牌色用于当前选择和主要动作，绿色用于抓取正常，红色用于异常。状态同时有文字，不只依赖颜色。

首页突出两块内容：“新消息”和“正在跟进”。统计放在小字、数量标签或一行提示中，不占用大块区域。详情、证据和次要操作按需要展开。

## 3. 首页

### 3.1 从上到下的顺序

1. 小标题“首页”，右侧为日期和刷新。
2. Made-in-China 与阿里国际站抓取状态栏。
3. 一行待处理提示：如“待审核 3 · 身份待确认 2 · 发送异常 1”。有事项时出现，各项可点击。
4. 主体左右两栏：“新消息”和“正在跟进”。

状态栏放在主体上方，打开首页即可看见。正常时很小；异常时扩展为明显的红色提示区域。

### 3.2 双平台状态栏：默认紧凑、绿色

两个平台独立显示、独立变更状态。默认正常样式为一条窄横栏，桌面端左右并排。

正常状态的示例文字：

> ● Made-in-China · 抓取正常 · 最近抓取 10:23
>
> ● 阿里国际站 · 抓取正常 · 最近抓取 10:24

绿色圆点与“抓取正常”使用绿色，时间使用较轻的中性色。两个平台共占一行，不额外放两张大卡片。时间是该平台最近一次**成功抓取完成**的时间；跨日时显示日期，如“09/29 18:42”。

正常抓取但没有新消息，仍保持绿色；可在详情里显示“抓取成功，本次无新消息”。用户不需要因为没有新消息而处理状态。

点击任一平台的状态，可打开右侧“抓取状态”详情，查看最近成功时间、最近检查时间、抓取结果和历史异常。平时这些内容保持收起。

### 3.3 异常状态：自动变大、红色

出现问题时，该平台自动展开为横向红色提示区：浅红背景、红色边线、醒目的标题和清楚的下一步动作。另一平台继续保持小绿条。

示例：

> **阿里国际站 · 抓取异常**
>
> 登录已失效，当前无法抓取新消息。
>
> 最近成功抓取：09/30 10:24 · 异常发现：10:36
>
> 【处理登录】 【重新检查】 【查看详情】

异常区的内容顺序固定为：

- 平台名称与“抓取异常”。
- 一句具体原因：登录失效、需要验证码、抓取服务中断、长时间没有完成抓取等。
- 对业务的影响：如“新消息暂未更新”，必要时显示“已中断 12 分钟”。
- 最近成功抓取时间与异常发现时间。
- 对应处理动作。

动作随原因变化。例如，登录失效显示“处理登录”；需要验证码显示“处理验证码”；服务中断显示“重新检查”和“查看详情”。首页展示业务人员看得懂的描述，详细记录放到侧栏。

异常栏不自动消失。手动收起后保留红色摘要“阿里国际站 · 抓取异常”，再次点击可以展开；新异常出现时重新展开。两边都异常时，两条红色区依次排列，分别保留原因和时间。

### 3.4 运行、检查与恢复

| 状态 | 状态栏呈现 | 时间与交互 |
| --- | --- | --- |
| 正常 | 小绿条，“抓取正常” | 显示最近成功抓取时间 |
| 正在抓取 | 保持紧凑，“正在抓取” | 完成前保留上次成功时间，不闪动、不反复改变高度 |
| 首次检查中 | 小栏，“正在检查” | 没有成功记录时显示“暂无抓取记录” |
| 抓取异常 | 自动展开红色区 | 保留最近成功时间，另列异常发现时间和原因 |
| 异常后检查中 | 保留红色异常区，动作显示“检查中” | 成功结果确认后再恢复正常状态 |
| 恢复正常 | 收回小绿条，“已恢复正常” | 更新成功时间，短暂提示恢复时间后回到“抓取正常” |

异常与恢复的变化轻柔，不弹出阻断业务的对话框。刷新状态时只更新状态栏，消息和跟进列表保持可用。

### 3.5 新消息

左栏按客户会话展示新消息，一条会话一行。每行包括：

- 客户姓名或公司。
- 来源平台：Made-in-China / 阿里国际站。
- 最近一条客户消息摘要。
- 消息时间与未读数量。
- 接待人，以及“待回复”“待审核”“身份待确认”等处理状态。

上方保留“待处理 / 未读 / 全部”和“我的客户”切换。点击会话进入消息中心，并打开对应消息；返回首页时保留原筛选与位置。

异常平台仍显示已抓取的历史会话，并就近提示“新消息暂未更新”。列表为空时显示“暂无待处理消息”，同时保留“查看历史消息”入口。

### 3.6 正在跟进

右栏按逾期、今天到期、接下来需要跟进的顺序展示事项。每项包含客户、下一步行动、负责人、截止时间和客户评级。

常用动作直接可见：“记录跟进”“安排下一步”“完成事项”。点击客户可以查看详情；点击事项可以编辑记录。完成事项后提醒安排下一步，保留已完成记录。

## 4. 消息中心

### 4.1 页面结构

左侧是会话列表，中间是聊天时间线和回复区，右侧是客户信息与处理动作。右侧可收起，给长消息和草稿更多空间。

顶部子标签：会话、待审核、发送任务。筛选以搜索、平台、状态、负责人为主，国家、未读、等待时间等放进“更多筛选”。

### 4.2 会话与回复

消息显示原文、译文、图片/附件、时间、发送者和发送状态。历史可以向上继续查看。AI 起草、人工修改和最终发送者分别标识。

回复区包含“撰写回复”和“生成 AI 草稿”。AI 草稿提供中文摘要、缺失信息、风险提示及引用资料。查看依据时在当前页面展开，仍能看到聊天上下文。

审核动作是“保存修改”“退回修改”“批准并创建发送任务”。批准后能继续查看任务状态；失败原因出现在对应任务和消息附近。全局外发状态放在审核区附近，用一句话说明当前是否允许任务执行。

### 4.3 身份、接管与转销售

客户未关联时，右侧显示“身份待确认”，提供匹配候选、确认关联和新建线索。候选展示名称和匹配依据，确认后更新客户资料。

“AI 辅助 / 人工接管”始终可见，切换动作就在状态旁。接管后明确说明未发送的自动任务暂停执行。

“转销售跟进”收集需求摘要、负责人和截止时间。创建后显示交接事项，客服与销售可以从任务回到同一会话。

待审核列表点击草稿后，打开对应会话与审核区。发送任务显示待发送、执行中、成功、失败等状态，失败时有原因、记录与后续处理入口。

## 5. 客户与评级

顶部子标签为“客户列表”和“历史洞察”。列表可以切换公司、联系人、潜在客户，并按平台、国家、负责人、阶段、评级搜索筛选。

### 5.1 客户列表与详情

列表优先显示名称、国家、来源平台、评级、销售阶段、负责人、最近沟通和下一步行动。选中后右侧打开详情。

详情分为：概览、沟通记录、跟进记录、销售业务、资料与作品。概览显示联系人、需求摘要、人工评级、销售阶段和下次行动；客户负责人和会话接待人分开展示。

评级使用 S / A / B / C。人工评级显示确认人、日期和依据；AI 建议单独标记为“待复核”，可以查看依据，再接受或调整。未评级显示“未评级”。

“销售业务”关联询价、报价/PI、样品、订单和交付进度，按当前客户归集。客户评级、销售阶段和跟进事项分别记录，避免完成一条任务就改变成交状态。

### 5.2 历史洞察

面向 Made-in-China 与阿里国际站的历史客户，支持按平台、负责人和分析状态筛选。

上方显示简洁的今日跟进建议；主体显示客户及历史进展；选中客户后展开需求摘要、最近动态、尚待确认的事实、建议动作和消息依据。

建议可以转成跟进事项，选择负责人和时间。证据链接直接定位到对应会话的相关消息。

同步范围和分析状态作为小字信息显示，能够区分已抓取、待更新、分析中、分析失败和待重新分析。源消息事实、AI 推断和人工确认信息有明确标识。

## 6. AI 工作中心

用于商品图片、宣传内容和视频创作。顶部子标签为“开始创作”“创作任务”“我的作品”。

开始创作的流程：

1. 上传商品图片，或从商品资料中选图。
2. 写一句构想，例如“突出包装和冷冻蓝莓品质，面向海外采购商”。
3. 选择用途、语言、画幅和时长，常用选项简洁呈现。
4. 查看少量推荐方案，每个包含简短说明、分镜和预期效果。
5. 选中方案后调整并开始生成。
6. 预览结果，修改、重新生成、下载，或关联商品和客户。

创作任务显示排队、生成中、完成和失败；失败保留输入和素材。作品按商品、客户和时间查找，能查看不同版本。

创作素材、参数和预览在同一工作区内完成，详情按选择展开。

## 7. 知识库

顶部子标签为“商品与规格”“证书与报告”“知识文档”“素材”。统一使用列表加详情的形式，能从商品找到相关规格、证书、文档和图片。

- 商品与规格：名称、中英文描述、规格、包装、起订量、适用市场和版本。
- 证书与报告：类型、适用商品或批次、有效期、审核状态、附件；到期或撤销状态明显可见。
- 知识文档：名称、分类、来源、版本、审核、生效日期、失效日期；打开后查看内容和引用情况。
- 素材：商品图、包装图、视频和资料附件，可用于创作或客户沟通。

常用动作包括新增、编辑、上传、关联商品和送审。资料中的已确认内容、内部备注和待核实信息分开展示；在草稿引用处可以回到对应资料。

## 8. 设置与抓取详情

设置保留账号、工作台偏好、平台抓取和执行端状态。

首页状态栏点击后直接打开相应平台详情，内容包括：

- 当前抓取状态及账号。
- 最近成功抓取、最近尝试和最近检查时间。
- 本次是否发现新消息、哪些内容更新成功。
- 登录、验证码等需要处理的问题。
- 异常发生、重新检查、恢复正常的时间记录。
- 处理登录、处理验证码、重新检查等适用动作。

平台抓取状态与消息发送状态分开标识。首页小条只回答“能否正常抓取”和“最近成功时间”；复杂记录在详情中查看。

## 9. 通用交互

- 列表选中、详情展开、返回时保留搜索与位置。
- 保存失败保留输入，明确指出哪一步失败并提供重试。
- 常用动作就近显示，详情用侧栏，短确认用弹窗。
- 全局搜索覆盖客户、会话、跟进事项和资料，选择结果后进入对应页面与记录。
- 手机端把双平台状态分为两条小行；异常仍自动展开。首页先新消息、后跟进，消息中心按会话列表、聊天、客户资料逐层进入。
- 状态始终包含文字，键盘可以操作；页面局部更新不打断正在编辑的内容。
