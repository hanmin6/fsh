# 权限基线

在 EspoCRM 管理后台按以下基线建立角色，实际人员通过团队与负责人字段分配数据范围。

| 角色 | 客户与统一询盘 | 草稿 | 批准发送 | 渠道/知识库 | 审计 |
|---|---|---|---|---|---|
| 管理员 | 全部 | 全部 | 是 | 配置 | 全部 |
| 老板 | 全部只读 | 全部只读 | 可选 | 只读 | 全部只读 |
| 业务主管 | 全部 | 全部 | 是 | 只读 | 只读 |
| 业务员 | 仅自己的 | 仅自己的 | 按授权 | 只读已审核 | 无 |
| 平台执行端 | 无 UI 登录 | 无 | Token 接口 | 无 | 仅写入自己的事件 |

生产环境应创建独立长随机 Token，并限制执行端接口只能从广州内网或 VPN 访问。`FUSANHE_OUTBOUND_PAUSED=true` 为全局停发开关。
