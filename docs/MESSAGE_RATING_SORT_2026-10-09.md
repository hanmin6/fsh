# 消息中心评级排序 · 2026-10-09

左侧来源平台下新增“排序”一行，默认“评级从高到低”，可切换“最新消息”。排序偏好保存在当前浏览器会话，切换排序、搜索或筛选时回到第一页。

评级顺序为 S 超高、A 高、B 中、C 低、D 超低；未评级、未关联或无法读取评级的会话排在已评级会话之后。同级按最后消息时间从新到旧，再以会话 ID 保持稳定顺序。评级始终来自关联的 Account、Contact、Lead，不使用会话中的旧评级值。

评级模式先按原生权限、搜索、来源平台及未读/待处理条件分批读取完整匹配会话，再批量读取客户评级，排序后按每页 30 条展示。分页切换不重新抓取完整会话。客户评级和已读取会话的缓存更新会刷新列表。客户请求每批最多 100 个关联 ID。最新消息模式沿用既有服务端分页和缓存。
