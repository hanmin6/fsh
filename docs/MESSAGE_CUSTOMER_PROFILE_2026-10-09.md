# 消息中心客户评级与背调 · 2026-10-09

消息中心原来直接读取 ExternalConversation 的 rating、ratingReason 和评级确认字段，但会话实体没有这些字段；真实评级保存在关联的 Lead、Account 或 Contact。因此已经评级的客户仍显示“待评级”。线上 36 个会话均已关联有评级的客户档案。

会话列表和首页消息现按关联客户批量读取评级，沿用 customerRef 的公司、联系人、线索优先级。相同客户只读取一次，最多按三种实体分别请求。读取中、无权限、失败、未关联分别展示对应状态，避免冒充待评级。客户缓存更新和人工调整会刷新会话评级。
