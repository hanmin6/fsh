# 福三和品牌与产品界面规范 v0.1

状态：从现有 UI 提炼的规范草案，待业务确认。适用于 CRM、员工 App、客户背调与 AI 素材创作；尚不是完整的企业 VI 手册。

## 设计定位

克制、可信、清晰、高效。通过红色皇冠与品牌红建立识别，用白色、灰绿表面和紧凑列表支持长时间办公。优先展示客户、询盘、产品、任务与其状态。

## 来源与版本

来源分支 `codex/web-workbench-hig`，提交 `9075d39`。
- `client/custom/res/fusanhe/brand.css`：历史品牌色、6px 圆角、34px 控件、40px 行高。
- `client/custom/ui/src/styles.css`：新版 React 语义色、14px 正文、6px 圆角、触控目标。
- `client/custom/res/fusanhe/README.md`：Logo 与工厂照片来源说明。

现有官网与新版 UI 的背景、边框和主色存在差异。建议新产品页面使用新版 React 语义色；旧页面逐页迁移。这里提炼规则，不代表现有全站已经统一。

## 标志与图像

沿用仓库 `logo-full.png` 红色皇冠原图，不拉伸、不改色、不重绘、不裁切。放在白色表面；深色导航提供白色承载区域。建议净空至少为标志高度的四分之一，这是本规范新增建议。小尺寸需实际检查可辨识度，不能直接把皇冠当作未经验证的 App 图标。

工厂和产品展示优先使用真实且获授权的照片。AI 场景图保留生成状态与审核记录；不能替代产品实物、认证证书或检验报告。

## 色彩

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 品牌红 | `#C83A28` | Logo 与品牌识别 |
| 操作深红 | `#AA3022` | 主按钮与重点操作 |
| 森林黑 | `#20251F` | 正文与深色导航 |
| 工作台底色 | `#F6F7F5` | 页面背景 |
| 白色表面 | `#FFFFFF` | 表格与内容区域 |
| 灰绿边界 | `#D8DED8` | 分隔线与描边 |
| 辅助文字 | `#526056` | 次要说明 |
| 成功 / 链接 | `#245B3C` | 完成状态与来源链接 |
| 待复核 | `#79541C` | 待处理与缺失信息 |
| 错误 | `#A62727` | 失败与破坏性操作 |

官网暖白 `#F7F5EF`、品牌边框 `#DCD8CE` 可保留给宣传或登录场景；金色 `#C7A36A` 只作为可选品牌辅助色，不用作正文或日常状态色。

红色主操作与错误色接近，必须靠按钮文字、错误说明和操作位置区分，不能只依赖颜色。每个操作区域保留一个主要按钮。避免满屏红底和红色图标。

## 字体、间距与尺寸

使用系统中文无衬线字体，见 tokens.css。正文 14px，表格 13px，辅助信息 12px，区块标题 16–18px，页面标题 20–24px；字重 400/500/600。比较数字使用等宽数字。

采用 4px 增量间距，以 8px 为基础节奏：4、8、12、16、24、32。默认圆角 6px；1px 边界；普通内容不加阴影，弹层可使用轻阴影。

旧界面控件基准 34px、表格行 40px；新版 React 按钮至少 36px，部分高频操作为 44px。新页面建议桌面 36px、触控目标至少 44px；内容换行时行高自适应。

## 页面与组件

左侧稳定导航 + 主工作区；客户详情可使用右侧检查面板。顶部保留标题、当前状态和主操作。桌面优先表格与列表，长表格在局部滚动。窄屏导航折叠，详情转单栏。

主按钮：深红底白字。次按钮：白底细边框。文字链接：深绿。所有交互有键盘焦点、悬停、禁用和处理中状态。

输入框使用可见标签；错误贴近输入项说明原因。表格中状态使用短文字，空状态说明下一步。模态弹窗仅用于简短确认，复杂任务进入详情页。

## AI 功能的统一表达

客户背调：来源事实、AI 推断、待核查项、建议行动分别呈现；每条结论关联来源与更新时间。证据不足显示“待确认”，不编造置信度。

回复草稿：突出客户上下文、引用知识、风险与人工审核。批准发送任务与实际发送状态分开。

生图 / 生视频：产品资料与创作参数在侧栏，预览占主要空间。显示草稿、生成中、失败、待审核、已入库。生成内容标注 AI 来源；成本仅在有依据时显示。

## 跨端使用

Web 与 App 共享语义色、状态名称和客户/产品数据对象。App 导航按移动任务重新组织，不能缩小桌面表格。PPT、宣传页可沿用品牌色和照片，但无需沿用工作台信息密度。

## 写作与禁用模式

用“发起背调”“生成草稿”“待复核”“查看来源”等具体动词。避免夸大的 AI 营销口号、紫蓝渐变、过多卡片、装饰性图表、无来源评分和大圆角铺满页面。

## 交付与使用

- `index.html`：浏览器风格展示页，包含颜色、排版、组件与 AI 示例。
- `tokens.css`：可选择性引入的语义变量，不会自动覆盖现有样式。
- 本文：产品和开发共同使用的设计规范。

建议后续设计任务引用：“沿用 docs/brand/STYLE_GUIDE.md 的福三和品牌与产品界面规范，复用现有 shadcn 组件，以 tokens.css 的语义角色为依据。”

完整品牌 VI 的印刷色、商标规范、App 图标和对外品牌口吻尚需独立确认；本草案不假定已有这些资产。
