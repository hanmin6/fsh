# 消息中心英文自动翻译（2026-10-09）

打开会话后，已加载的英文消息自动翻译为简体中文。中文译文直接显示在原文下方，收件和已发消息均支持。加载更早消息或消息缓存更新时，会继续处理新增的英文消息。已有平台译文直接复用。失败消息保留原文，并提供“重试翻译”。

## 数据与调用

- 新增 `POST /Fusanhe/conversation/:id/translate`，仅接收 `messageIds`（1–6 个）与可选 `retry`，正文从服务器读取。
- 整批检查会话、每条消息的记录读取权限以及 `body` / `translatedBody` 字段权限；消息必须属于指定会话。
- 使用现有 `TextGateway` 默认文本模型。翻译不生成回复草稿、发送任务或对外消息。
- 复用现有 `ExternalMessage.translatedBody`，无需新增字段或数据库迁移。消息正文、方向、会话、内容哈希、发送时间、附件与投递状态保持原样。
- 同一会话由文件锁避免并发付费调用。按消息 ID 和原文内容哈希保存私有缓存；成功、无需翻译的结果复用，失败冷却 10 分钟，人工重试可提前重试。
- 纯中文、纯网址和邮箱在本地跳过；模型判别英文与其他语言。中文夹杂英文可翻译英文部分。
- 长消息按 UTF-8 安全边界分段，每段至多 8,000 字节，每次模型输入消息正文合计至多 12,000 字节、6 段；超过 64,000 字节明确显示无法自动翻译，不截断原文。输出限额最多 8,192 tokens，原有其他模型调用仍默认 1,600。
- 模型输出须与输入 ID 一一对应，有中文译文，并保留数字、SKU、网址与邮箱；不合格结果不保存。输入消息中的指令作为待翻译文本处理。
