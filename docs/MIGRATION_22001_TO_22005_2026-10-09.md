## SSH 与登录入口

使用已有 SSH 密钥，主机别名为 `tunnel-22005`，用户为 `fusanhe`。以下示例不包含密钥内容或密码：

```bash
ssh -i ~/.ssh/tunnel_operator_ed25519 -o IdentitiesOnly=yes \
  -o BatchMode=yes -o StrictHostKeyChecking=yes -o HostKeyAlias=tunnel-22005 \
  -o 'ProxyCommand=ssh -o BatchMode=yes -o ConnectTimeout=10 -W %h:%p root@8.138.165.27' \
  -p 22005 fusanhe@127.0.0.1
```

需要查看平台浏览器或 Dify 时建立本机转发：

```bash
ssh -N -i ~/.ssh/tunnel_operator_ed25519 -o IdentitiesOnly=yes \
  -o BatchMode=yes -o StrictHostKeyChecking=yes -o HostKeyAlias=tunnel-22005 \
  -o ServerAliveInterval=15 -o ExitOnForwardFailure=yes \
  -o 'ProxyCommand=ssh -o BatchMode=yes -o ConnectTimeout=10 -W %h:%p root@8.138.165.27' \
  -p 22005 -L 127.0.0.1:16080:127.0.0.1:6080 \
  -L 127.0.0.1:18088:127.0.0.1:8088 fusanhe@127.0.0.1
```

本机打开 `http://127.0.0.1:16080/vnc.html` 与 `http://127.0.0.1:18088`。平台登录、验证码由账号持有人完成；VNC 密码从服务器 `private/login-handoff.txt` 或已有受限交接目录获取，不写入仓库。关闭转发后 localhost 入口失效，公司内网 Dify 地址继续可用。
